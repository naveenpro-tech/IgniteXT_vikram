# IgniteXT Platform - Project Summary

## 📋 Overview

**Project Name**: IgniteXT  
**Type**: Student Community Platform (Website + Progressive Web App)  
**Mission**: Empower students through coding education, career guidance, and mentorship  
**Timeline**: 20-22 weeks (5-6 months)  
**Status**: Planning Complete ✅ | Ready for Development 🚀

---

## 🎯 Core Objectives

1. **Learning & Development**
   - Provide structured learning through interactive roadmaps
   - Track student progress with detailed analytics
   - Offer practice problems with integrated code editor

2. **Community & Mentorship**
   - Enable 1:1 and group mentorship sessions
   - Foster community engagement through forums
   - Support mental wellness with anonymous chat

3. **Career Guidance**
   - Explore career paths with detailed insights
   - Provide skill roadmaps for different tech stacks
   - Offer placement preparation and guidance

4. **Engagement & Growth**
   - Gamify learning with badges and leaderboards
   - Organize workshops and coding contests
   - Build a sustainable student-first community

---

- ✅ Contest participation tracking
- ✅ Homepage with announcements banner

**Deliverables**:

## 🛠️ Technology Stack

### Frontend
- **Next.js 14** (App Router, TypeScript)
- **Tailwind CSS** + **shadcn/ui**
- **Zustand** (state management)
- **React Query** (server state)

### Backend
- **Supabase** (PostgreSQL, Auth, Storage, Real-time)
- **Next.js API Routes**

### Deployment
- **Vercel** (frontend hosting)
- **Supabase Cloud** (database)
- **GitHub Actions** (CI/CD)

### Additional Services
- **OpenAI GPT-4** (AI chatbot)
- **Resend** (email service)
- **Sentry** (error tracking)
- **Vercel Analytics** (analytics)

## 🔄 Development Workflow

### Git Workflow
```
main (production)
  ↑
develop (staging)
  ↑
feature/* (feature branches)
```

### Sprint Cycle
- **Duration**: 2 weeks
- **Planning**: Monday (Week 1)
- **Daily Standups**: 15 minutes
- **Review**: Friday (Week 2)
- **Retrospective**: Friday (Week 2)

### Code Review Process
1. Create feature branch
2. Develop feature
3. Write tests
4. Create pull request
5. Code review (2 approvals)
6. Merge to develop
7. Deploy to staging
8. QA testing
9. Merge to main
10. Deploy to production
